# Cheatsheet

## If / then (call path)
- **They answered** → context-first opener (never “how’s your day” / “bad time” / “is this Bob?”).
- **Have peer proof** → Heard The Name (Feet-Up). **Have a triggering event** → Tailored Permission (Arms-Up). **Neither** → untailored permission.
- **Heard The Name = no** → stay in character, joke, Problem Prop. **= yes** → “What’d you hear?” then prop anyway.
- **Permission denied** → interruption, not product; incentive why, re-ask 30s.
- **After opener** → Problem Prop (trigger → one-sentence X → interest CTA). **Never** value-prop buzzwords/categories.
- **Interest yes** → ranges, 1–2 weeks, email live, “please accept,” dart + backups if they stall.
- **Interest no / objection** → Miyagi. **They start asking you questions** → book (stop stacking Miyagi).

## Opener choice
| Situation | Use | Avoid |
|---|---|---|
| Peer group you can name | Heard The Name | Pleasantries |
| Event tied to the problem | Tailored Permission | Alma-mater trivia |
| No research time | Untailored permission | “Bad time?” (~2.15%) |
| Unknown if right human | Assume the name | “Is this Bob?” |

Gong meeting success (openers): bad time 2.15% · how’s it going 7.60% · permission 11.18% · tossed around 11.24%. Product language: buzzwords 5.5% · social proof 12% · problem 16%.

## Miyagi in 10 seconds
1. Pause 2s. Micro-agree. Specific agree. Slow / laugh.
2. “So no one calls again” + 2–3 choices (pile onto *their* side).
3. Mini push-away + test drive (why look if they never buy).
4. New objection → restart at 1. Median win ~4.8 min, 2+ objections.

**Generic test drive:** not for now — so they know what’s out there.

## Objection map
| Hear | Bucket | Do |
|---|---|---|
| Not interested / 6 months / send info | Dismissive | Reveal real reason; then Miyagi. 6 months: test-drive *today* if real trigger; else treat as fake. |
| Wrong person | Dismissive | Name the right title; name-drop permission; *you* email. |
| Number? / in a meeting / “cold call!?” / wrong person at door / hang-up | Pre-pitch | Blunt + back to PBO. Meeting: invite now vs talk now (no “I’ll call later”). Hang-up: log 3 facts, wait ~1 week. |
| Budget / price / bandwidth / hire first / not for XYZ | Situational | They win today; car later. Flexibility ≠ locked discount. Ego-boost experts. |
| In-house / competitor known / unknown / in contract | Existing | Agree → trap → peer proof. Unknown: multiple-choice + two different incentives. Contract: no rip today. |

Top 5 ≈ 74% of objections — master those plus *your* local list before the long tail.

## Gatekeeper / VM
- GK: Slide-by → context → social proof. Questions back. No pitch, no buddy act, no identity lies. Shut down 1–2× → cell / off-hours / other channel (−39% with GK).
- VM: max 2; name last; point to email; never callback-ask; never pitch. #1 15s context. #2 30s + proof. Rotate numbers (−28% future connect if you out yourself; ~2× email reply).
- Email 1 = full prop. Later touches = arrows back.

## Golden 3
- **Connect**: mobiles/directs; tag red/yellow/green; tree codes; 5 dials/4 weeks then rest; 2 VMs; register/rotate/test numbers; 8 a.m.–9 p.m.; never emergency-double, *67, FaceTime.
- **Set**: DQ 30s → A now / B problem / C ICP → extra 2 dials A/B → whole account, call high → intent (5× opens, pricing, objection reply, new event) first.
- **Show**: day-before assume-on + prep detail; + week-before if ≥2 weeks; late: email 2 / call 5 / call 8; no-show: **punt invite 3–4 days**, don’t delete.

Parallel dialer: huge territory yes; small enterprise no (lose context).

## Calendar / volume
- Perfect time = when you will actually do it (morning also empirically best). Skip-day costs ~40 dials.
- 10 dials before other morning rituals. Inbox 8:30 / 12 / 3 only.
- Green 8–12 prospect (calls first) · Yellow 12–3 customers · Red 3–6 admin/research.
- Customer takes a Green slot → **move** the blitz inside Green; never delete it.
- 60 tasks ready, 60 min, 40 dials, DND, no linger. AE 1h/day (~150–200/wk). SDR 2h (~300–400). Raise if needed; **never lower**.
- Reluctance: MV tracks + ~50 reps, then contract (first / daily / weekly + stick). Excuse sentences are not strategy.

## Benchmarks (800 dials / Gong)
Average ~43 connects / 2 meetings. Top quartile ~106 connects / 18 meetings. Top 10% ~1 meeting per 3 connects. Calls also lift email even without a live connect.
