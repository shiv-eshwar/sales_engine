# Book skills (knowledge packs)

These directories are synthesized Agent Skills from sales books the operator owns. They are **not** Eve runtime agents.

The four Eve agents the app actually invokes are siblings of this folder:

- `../live-coach` — one short cue during a connected call
- `../post-call` — CRM proposal after hang-up
- `../campaign-generation` — campaign strategy from an offering
- `../prospect-research` — pre-call brief

Live coaching auto-loads distilled rules from [`config/playbooks/cold-calling.yaml`](../../config/playbooks/cold-calling.yaml). Do not paste these books into the live prompt (cues are capped at 160 characters).

When editing the playbook or an objection guide, read the matching skill:

| Skill | Use when |
|---|---|
| [farrokh-cold-calling-sucks](farrokh-cold-calling-sucks/SKILL.md) | Openers, Problem Proposition, Mr. Miyagi, gatekeepers, voicemail, dial conversion |
| [blount-fanatical-prospecting](blount-fanatical-prospecting/SKILL.md) | RBOs, Power Hours, pyramid, talk ratio, two-brush-off NEXT |
| [weinberg-new-sales-simplified](weinberg-new-sales-simplified/SKILL.md) | New Sales Driver, sales story, meeting as the win, reflex resistance |
| [sobczak-smart-calling](sobczak-smart-calling/SKILL.md) | Possible Value Proposition, intel, never-say list, Smart Questions, screeners |

Content is study notes, not the books. Keep private if the source is third-party copyrighted material.
