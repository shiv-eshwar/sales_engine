# Chapter 7: How to Be Smart with Voice Mail

## Core Idea
Leave voicemail. Do not expect a callback. Objective: pique curiosity with possible value so they take the next live call. The message is almost identical to your interest-creating opening (Ch 10); the ending is “I’ll call back” plus slow contact info.

## Frameworks Introduced (When / How)
- **Voicemail = opening + callback close**: Use on every Smart Call attempt that hits a box.
  - How: Same intel + PVP + “I’d like to ask a few questions…” Then: you will call Thursday morning; number twice, slowly; email. You control the communication.
  - Why it works: You already did the heavy lifting. A value hint can create “what might that be?” Empty or gimmick messages get deleted.
  - Failure mode: Winging “uhhh,” begging them to call you back, or hanging up at the beep.

- **Lowered-expectations rule**: Use to stay sane.
  - How: Overworked buyers with 79 emails will not return a stranger. Flooded-basement urgency is the exception. Persistence plus a repeated value imprint beats one-and-done.

- **Repeat the same PVP message**: Use on touches 2–N.
  - How: Do not reinvent. Radio repeats the benefit. Prospects do not remember every word; trainers miss items on a second immediate playback. Varying the PVP throws away the imprint.
  - How many: No magic number (3, 5, 8). Judge by account importance. One message ≈ no chance. Some buyers only consider reps they recognize from several interesting messages.

- **Last-resort / “I’m done” message**: Use when the pool is large enough or the file is exhausted.
  - How: “I’ve tried several times about cutting customer-acquisition cost 20 percent like we did for B.O. Industries. If I don’t hear back, I’ll assume this isn’t something you want to discuss now.” Often gets a response, even an apology. One software rep’s 48th-attempt “I will not call anymore” got a laughing callback and a sale.

## Key Concepts
- **Length is interest, not word count**: Opera is long if you hate opera; a brisket recipe can run. Targeted PVP is not “too long.”
- **Listen to the entire greeting**: Alternate office, assistant, others who can help, pronunciation, return date, what they are doing.
- **Tone match**: Rushed greeting → be crisp; warm greeting → slightly more informal.
- **Map the tree**: Log “# then 23.” Opt out with 0, *, #, or wait for a human. Listen to department prompts and directories for titles and pronunciations.
- **Call right back**: They may have just missed you. Vary times; ask the assistant when they are at the desk.
- **Number twice, pause, write it as you say it**: “Here’s my number” then pause for a pen (etiquette). Repeat at the end.
- **Review if the system allows** — never assume you can rerecord after “message delivered.”
- **Stand out physically**: Ask assistant to scratch a note (even on the chair), optional smiley, reinforce with email. Still must be about their world.
- **Unreturned-mail email**: List dates you tried; “advanced apologies — did I do something wrong?” One rep reported ~90% reply after months of silence.
- **Send email with more info** as a complement so they have you in the inbox.

## Mental Models
- Use voicemail to **earn the next connect**, not to close the deal in a box.
- Think of each message as **another repetition of the same commercial**, not a new creative brief.
- Prefer **you will call them** over “I’ll be waiting by the phone.”
- Treat **shady mystery messages** as reputation poison.

## Anti-patterns
- **IRS / hospital-lab fake urgency.**
- **Name and number only** so they “have to” call back. When they discover the tactic, they skewer you.
- **Hang-up teaser**: “I have the most unbelievably great news about—” click. Ends do not justify means.
- **“Please call me; I’ll be waiting.”**
- **Hanging up at voicemail** and discarding the name after three tries.
- **Changing the PVP every touch** because you are bored.
- **Not giving the number slowly**, forcing a rewind.

## Worked Example
Paraphrased Smart voicemail: “Hi Michael, Pat Stevens with Insurance Partners. Hope the golf trip was good. Suzanne said you’re evaluating how to attract and keep top talent across locations. We’ve helped companies in that spot lower recruiting cost and raise managerial retention. I’d like to ask a few questions to see if I could provide information. I’ll try Friday morning. If you want me sooner: 555-… I’ll repeat that. Email pat@…”

Same body as the live opening; only the close changes.

Last-resort paraphrase: “I’ve tried several times about reducing customer-acquisition cost like we did for [peer]. If I don’t hear back I’ll assume you don’t want to discuss it now.”

## Key Takeaways
1. Always leave a prepared, PVP-based message; do not expect a return call.
2. Voicemail copy ≈ opening copy; you announce the callback.
3. Repeat the same value imprint; judge cadence by account value.
4. Listen all the way through; log intelligence and the phone map.
5. Number twice, slowly; reinforce with a human note and/or email.
6. Use a firm last-resort message before you punt.
7. Never use mystery, fake-cutoff, or fake-authority tactics.
