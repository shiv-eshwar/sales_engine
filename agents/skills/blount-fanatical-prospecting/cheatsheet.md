# Cheatsheet — Fanatical Prospecting

## Channel: what to use when

| Situation | Do this | Because |
|---|---|---|
| Need coverage + live answers today | Phone Power Hour (25–50 dials) | Highest efficiency *and* live effectiveness |
| Complex/high-cost first meeting | Phone → dual-calendar appointment | Time is the hard ask; don’t close on the interrupt |
| Transactional inside / low-risk | Phone or knock: qualify + close now | Appointment theater wastes the cycle |
| Local SMB, already have hubs on calendar | Hub-and-spoke IPP + T-Calls | Density beats windshield; still not IPP-only |
| Dense urban grid (e.g. Manhattan) | Lean in-person vs. rural phone | Walking beats dialing between floors |
| New territory / startup database | Heavy phone + knocking to qualify | Veteran’s mix is earned, not copied |
| Tenured, known windows | Referrals, social, timed calls, nurture | Cold shrinks; don’t go social-only |
| Biggest accounts ignore inbound | Interrupt (phone/in-person) | They already have a line at the door |
| Need research, triggers, BIC map | Social in Platinum Hours (30–60 min) | Social is not selling; phone conversion dwarfs it |
| Email vs social for response | Email (10–20× social) | Still one-to-one, never bulk |
| Skip a brutal gatekeeper | Early/late, InMail, handwritten, events, press-1 sales | No trick past GKs; sidestep |
| Known relationship, window or trigger | Text after phone/meeting | Text alone ~4.8%; after phone +112.6% conversion |
| Stranger’s mobile | Do **not** cold-text | Personal domain; you are spam |
| “I’m better in person/on LinkedIn” | Add the phone anyway | Avoidance, not data; pipeline is the scoreboard |

## Power Hour (do / don’t)

**Do:** Sacred first 1–2 hours. Pre-built pyramid list. DND. Phone/email off. Notes on the list. One objective. 10-call chunks. Eat the frog — do not time “best day.”
**Don’t:** Open inbox first. CRM-log each call. Research inside the hour (that’s Platinum). “How are you?” Pause before the ask. VM every unqualified name.

**Worth check:** Annual goal ÷ (weeks × Golden Hours) = $/hour. If the task is $10 work, delegate or move to Platinum.

## Five-step live call (≤10 seconds to the ask)

1. “Hi, [Name].”  
2. You + company.  
3. “The reason I’m calling is [objective].”  
4. Because (their problem, emotion, proof).  
5. Assumptive time → **shut up**.

VM if it matters: ID → number twice → reason → curiosity → name + number twice → 30s.

## RBO in three beats

| They say | You do |
|---|---|
| Reflex (“not interested,” “happy,” “busy”) | Anchor + unexpected agree/takeaway + re-ask time |
| Brush-off (“send info,” “call later”) | Specify or book; don’t accept as a win |
| Real objection + because | Shift: qualify window or book later anyway |
| Second no | Gracious exit; return another day. NEXT. |

Never: overcome/argue, “I understand,” fight past two RBOs, dwell on the scream.

## Pyramid: who you call first

1. In-window + hot inbound/referrals (today, while fresh)  
2. Conquest nurture / stakeholder / trigger watch  
3. Semi-qualified — fill holes, find windows  
4. Unknown mass — data + qualify  
5. Delete bogus/never/wrong size  

**Appointment only if** both calendars. **Ugly deals** (no DM, no budget, locked contract, not in window) — don’t swing.

## Replacement & slump

- Close 1 at 10% → replace ~10, not 1.  
- This month’s prospecting = next 90 days.  
- Slump? Start prospecting; ~30 days; stop recycling dead names.  
- Empty pipe + “must have this deal” = Law of Need; you already under-prospected.

## Desire filter (when excuses start)

How bad do you want it? → make one more call.
